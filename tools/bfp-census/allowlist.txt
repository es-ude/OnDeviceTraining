# Permitted calls, each SCOPED to one root (<source.c>:<function> as the roots
# file names it), so an entry never hides another root's hits.
#   <root> <function>                  traversal stops at <function> under <root>
#   <root> <function> <symbol> <count> exactly <count> call sites of <symbol> in
#                                      <function> are allowed under <root>; more
#                                      are hits, fewer make the entry stale
#                                      (--strict fails on both)
# Policy (integer-only BFP forward): no float/double/libm/int64 outside the two
# float boundaries; no BFP-specific division per MAC. Allowed divisions run per
# call, per group change, per output element, or are the index math the FLOAT32
# arm shares (same-algorithm rule).
