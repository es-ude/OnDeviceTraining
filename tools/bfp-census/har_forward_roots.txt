# The HAR classifier's integer BFP forward (examples/har_classifier/train_c_bfp.c,
# BFP wires, native math): the --strict gate.
#   <source file> <function base name>         walk the root and everything it calls
#   <source file> <function base name> self    the function's OWN call sites only
# The kernels are reached through executeOp's function pointer and the conversion
# cells through conversionMatrix, so each is its own root. The dtype dispatchers
# (executeOp, the layers' forward switches) are `self` roots: a walk from them
# reaches every dtype's arm, so only their own bodies are checked. Their one float
# route on this path -- staging a FLOAT32 operand -- is closed at run time by
# executeOp's forward check.
#
# Boundaries (allowed float, see allowlist.txt). These two stop at themselves:
# their rows document the boundary and check nothing.
QuantizationLayer.c quantizationForward
TensorConversion.c  convertFloatTensorToBfpTensor
TensorConversion.c  convertBfpTensorToFloat32Tensor
# The funnel (prologue, raw setup, epilogue dispatch) and the conversion entry:
ExecuteOp.c         executeOp            self
ExecuteOp.c         writeOutConversion   self
# Operand unpack (executeOp prologue, BFP-stored operands):
TensorConversion.c  unpackSignExtend
# Layers, in model order (dispatch wrapper, then kernel):
